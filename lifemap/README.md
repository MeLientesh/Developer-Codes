# Life Map Project

## Overview
The Life Map project is an interactive application designed to visualize a user's knowledge, skills, habits, goals, projects, relationships, achievements, and aspirations as a dynamic graph. This tool aims to help users better understand their personal and professional development by providing a visual representation of their interconnected elements.

## Features
- **Dynamic Graph Visualization**: Users can see their knowledge, skills, and goals represented as nodes in a graph, with relationships illustrating how these elements connect.
- **Interactive CLI**: A command-line interface allows users to input data and retrieve visualizations easily.
- **Web Interface**: Users can interact with their Life Map through a web browser, making it accessible and user-friendly.
- **Data Importing**: The application supports importing data from various sources, enabling users to integrate existing information into their Life Map.
- **Unit Testing**: Comprehensive tests ensure the reliability and correctness of the application components.

## Installation
1. Clone the repository:
   ```
   git clone <repository-url>
   ```
2. Navigate to the project directory:
   ```
   cd lifemap
   ```
3. Install the required dependencies:
   ```
   pip install -r requirements.txt
   ```

## Usage
To start the application, run the following command:
```
python src/lifemap/main.py
```
Follow the prompts in the command-line interface to input your data and explore your Life Map.
